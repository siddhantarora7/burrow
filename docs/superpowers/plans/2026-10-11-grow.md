# Pets grow up: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** koban earned from finished tasks and quick replies, spent to feed and play; pets grow baby → grown → evolved; six species; a per-garden catalog and weekly leaderboard.

**Architecture:** pure rules in `packages/core/src/grow.ts`, folded per event in PetDO next to the wait ledger; BurrowDO stores members' public growth and the garden catalog and relays care; the web renders stages, care controls and two panels.

**Tech Stack:** TypeScript, Cloudflare Workers + Durable Objects, Next.js 16, canvas pixel sprites, vitest.

**Spec:** `docs/superpowers/specs/2026-10-11-burrow-grow-design.md`

## Global Constraints

- The hook wire format stays `{v, type, at, session}`; no new event type.
- Web tokens may hello, poke and care, never post events.
- Lowercase copy; Zen Maru for chrome; pills per DESIGN.md (`.pill`, `.pill-btn`, `.lbl`, icons from `components/icons.tsx`).
- Pixel rules: whole pixels, 1 px `pet-ink` outline, pets brighter than the scene, no alpha in the canvas.
- No new dependencies. npm 12 (`npx -y npm@12 install`). No Claude attribution in commits.
- Numbers exactly as the spec's tables: pays 3 / 2 / 1, caps 30 stops and 20 replies a day, feed 5 → +10 xp, play 3 → +5 xp, grown at 100, evolved at 400, legacy pets 100 xp.

## Review Focus

1. A wait spanning the pet's midnight: pays on close and counts against the new day's cap.
2. Two care presses racing from two tabs: PetDO is single-threaded, so the second sees the lowered balance; never negative koban.
3. A pet in several gardens: care and earnings reach every garden; the catalog of each grows independently.
4. Legacy members (no `growth`): render grown, rank with 0 koban this week, count as `species:grown` in the catalog.
5. A socket without a proven `me` sending `care`: ignored.

### Task 1: core rules

**Files:** create `packages/core/src/grow.ts`, `packages/core/test/grow.test.ts`; modify `species.ts` (six species, `kinako`, defaults), `protocol.ts`, `index.ts`.

**Produces:**
- `STAGES = ['baby','grown','evolved'] as const`, `type Stage`, `GROW` constants, `LEGACY_XP = 100`.
- `interface PetGrowth { xp: number; koban: number; week: string; weekKoban: number }` (public).
- `interface Growth extends PetGrowth { day: string; stops: number; replies: number }` (PetDO only).
- `stageOf(xp): Stage`, `nextStageAt(xp): number | null`, `weekOf(day: 'YYYY-MM-DD'): 'YYYY-Www'` (ISO 8601).
- `newGrowth(day, xp = 0): Growth`, `publicGrowth(g): PetGrowth`.
- `earn(g: Growth, prev: WaitLedger, ev: Ev, day: string): Growth` (rolls day/week first; stop pays 3 under the cap; a non-opening event closing `prev.open[ev.session]` pays 2 within 60 s, 1 within 3 min, under the reply cap).
- `type CareAction = 'feed' | 'play'`, `isCareAction`, `care(g, action): Growth | null`.
- `formKey(species, stage) = 'species:stage'`, `growthOf(m: { growth?: PetGrowth }): PetGrowth` (legacy → 100 xp, 0 koban).
- protocol: `Member.growth?`, `MemberProfile.growth?`, `event.growth?`, `snapshot.catalog: string[]`, `ServerMsg grow`, `ClientMsg care`.
